# Паспорт проекта «Пульс дня»

**Версия:** 1.3.0. **Дата итоговой проверки:** 26 ноября 2026 г.

## Назначение

Личный планировщик для пользователя, работающего над несколькими проектами. Решает задачу построения расписания с учётом встреч, длительности и приоритетов задач; показывает, какие задачи не помещаются в рабочий день.

## Происхождение и вклад

Проект выполнен на основе готового учебного примера курса «ChatGPT и Codex» (урок «Публикация и монетизация», Илона Бортник). Исходная функциональность сохранена. Вклад в рамках учебной работы — публикация проекта на GitHub, подготовка онлайн-демо и релиза, дополнение README ссылками, выполнение пользовательских проверок и оформление доказательств. Самостоятельная разработка исходного кода не заявляется.

## Границы итоговой проверки

Основной сценарий: выбор даты, заполнение дня демонстрационными данными, построение расписания, добавление задачи и обработка недостатка времени, сохранение плана в браузере. Для него не нужны сервер, аккаунт или ключи API. В версии имеются дополнительные функции, включая пересчёт при добавлении встречи, перенос задач, импорт и экспорт календаря и резервное копирование; их полный повторный тест в итоговую проверку не включён.

## Критерии готовности

- Публичный репозиторий с README, инструкцией запуска и доступной онлайн-версией.
- На демонстрационных данных шесть задач размещаются в пределах рабочего дня с учётом трёх фиксированных встреч и перерывов.
- Пустой день отображается без ошибки; задача без названия не сохраняется.
- При недостатке непрерывного свободного времени задача выделяется как не помещающаяся в план.
- После обновления страницы и переключения между датами данные сохраняются в том же браузере.
- Фактические результаты, ограничения и скриншоты доступны в протоколе [ACCEPTANCE.md](ACCEPTANCE.md).
